# Eternal Note

**Permanent notes on Arweave that can earn you money.**

Owned by [@okfreelancer](https://github.com/OkfreelancerAi) / OkfreelancerAi.

## What it does

- Connect your Arweave wallet (Wander / ArConnect)
- Write a note and publish it permanently to Arweave
- Every note is tippable — tips and AI agent payments (x402-ready) go **directly** to your wallet
- No middleman. Withdraw anytime from your wallet.

## Live demo

Open `index.html` in a browser with Wander or ArConnect installed.

Or deploy to Vercel / any static host.

## Features

- Permanent storage on Arweave
- Direct earnings to creator wallet
- x402 / agentic payment ready tags
- Clean dark UI
- Single HTML file, zero build step
